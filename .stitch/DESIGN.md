# Design System: VIETWANDER AI

Project ID: 1439968317747880611

## Visual Theme
Premium cinematic travel intelligence with Vietnamese warmth, global editorial imagery, practical planning density, and local-first AI trust.

## Color Palette
- Deep Navy #071827: app shell, hero overlays, admin surfaces.
- Emerald Teal #0F8B7B: primary action, AI confidence, active filters.
- Sunset Orange #F97316: CTA, booking emphasis, route highlights.
- Ivory Sand #F8F3EA: calm page background and mobile surfaces.
- Mist Blue #DCEFF3: map cards, secondary panels, quiet tags.

## Typography
Web uses Inter or Geist-style grotesk. Mobile uses platform system font. Headlines are bold and editorial; dashboards use compact readable labels and tabular numbers.

## Components
Hero search command bar, travel cards, AI assistant bubble, itinerary timeline, budget simulator, comparison table, booking cards, admin data tables.

## Motion and Accessibility
Subtle reveal, hover lift, shimmer loading, keyboard focus states, strong contrast, and reduced-motion fallback.
